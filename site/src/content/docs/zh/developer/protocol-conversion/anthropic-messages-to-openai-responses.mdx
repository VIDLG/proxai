## 跨轮 thinking continuation

Anthropic thinking signature 与 redacted-thinking payload 是 provider-scoped 数据，
但客户端将 assistant 历史回放给 Anthropic 时必须保留它们。对于
`anthropic_messages` → `openai_responses`，ProxAI 把带版本的 continuation
envelope 写入标准 Responses `reasoning.encrypted_content` 字段。后续收到
`openai_responses` → `anthropic_messages` 请求时，ProxAI 会识别该 envelope、
从 Responses 表示中剥离，并恢复原始 Anthropic `thinking` 或
`redacted_thinking` block。

这是客户端携带的状态，而不是代理持久化；只有客户端保留并回放 Responses
reasoning item 时才能跨轮续接。该 envelope 带前缀且以 JSON 编码，并非密码学
加密或认证；`encrypted_content` 只是既有的 Responses 承载字段名。未知的
`encrypted_content` 是 provider-scoped 数据，在 Responses-to-Anthropic 转换中会
trace 后跳过；只有带版本 ProxAI 前缀的数据才会被识别为可恢复 continuation。

<ProxaiCallout type="caution" title="一个 Anthropic message 可以变成多个 Responses items">
  非流式 Anthropic 返回一个 `Message`，但 Responses `output[]` 可以包含多个 typed items。不要把这个转换建模成一条 message 对一条 message。
</ProxaiCallout>

## 有损区域

- Anthropic content block `index` 是 stream-local；Responses item identity 是客户端可见且可跨轮稳定的。
- Provider-specific thinking metadata 只有在客户端回放 ProxAI continuation envelope 时才能保留；其他 provider-specific metadata 仍可能没有 Responses 等价物。
- Anthropic `pause_turn` 和 refusal metadata 需要保留行为的目标语义。
- Usage 和 stop metadata 可能在 stream 后段才到达。
