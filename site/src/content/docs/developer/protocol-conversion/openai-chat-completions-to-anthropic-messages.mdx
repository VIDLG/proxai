<ProxaiCallout type="caution" title="Chat has weaker identity">
  Chat Completions has no Responses-style output item identity. Tool-call `index` is only meaningful inside one streamed choice. Avoid building cross-turn semantics on it.
</ProxaiCallout>

## Lossy areas

- Chat has no native output item graph.
- Plain thinking text is preserved through the `reasoning_content` compatibility extension. ProxAI appends its versioned continuation suffix only for compatible clients that replay it; Chat itself still has no native per-item identity or signature field.
- The continuation suffix can preserve redacted/encrypted thinking across ProxAI's Anthropic conversion pair, but is not a portable Chat Completions feature.
- Chat streaming uses `tool_calls[].index`; Anthropic streaming uses content block `index`.
- Chat `[DONE]` is a stream carrier terminator; Anthropic `message_stop` is the semantic terminal event.
